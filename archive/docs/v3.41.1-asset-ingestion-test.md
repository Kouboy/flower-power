# v3.41.1 — Asset Ingestion Test

Cette passe valide le pipeline `Asset Editor -> PNG + JSON -> Flower Power` sans refaire le gameplay.

## Assets intégrés

Onze familles courantes utilisent désormais les PNG authorés : pneu, panneau solaire, sac poubelle, serveur, drone, extincteur, micro-ondes, cône, fût nucléaire, batterie et cercueil.

Le dinosaure `NON AUX ESSAIS NUCLÉAIRES` est traité séparément comme rencontre signature rare. Il reste absent de certaines parties, n'apparaît jamais plus d'une fois et peut être forcé avec `?talisman=1`.

## Collisions

Pour chaque asset authoré :

- `render.worldWidth` fixe sa taille en unités du monde ;
- `render.pivot` fixe son pivot ;
- `render.mirrorSafe` décide si le sprite peut être retourné horizontalement ;
- `collision.points` remplace les approximations SDF précédentes ;
- `collision.grazeRadius` fixe directement l'enveloppe de flyover en unités du monde ;
- `collision.flyoverEligible` prépare le futur système de récompense par prise de risque.

Les exports JSON de l'éditeur sont conservés tels quels dans `assets/obstacles/`. Un `manifest.js` est généré à partir d'eux afin que le prototype continue à fonctionner lorsqu'on ouvre simplement `index.html`, sans serveur local.

## Power-ups

Aucun power-up n'est désormais placé pendant la génération du niveau. Les fonctions de bonus restent dans le prototype pour la prochaine étape, mais `game.bonuses` démarre vide.

La règle de design retenue est :

`flyover -> mesure de la prise de risque -> nature/valeur du power-up -> matérialisation légèrement en avant de la pousse`.

Ce système n'est pas encore implémenté dans cette passe d'ingestion.
