# Boutique de fin de pousse — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** après chaque pousse, un bon de commande en papier recyclé propose 3 articles tirés au sort (un à −50 %) ; on coche, on commande, le score baisse et les articles s'appliquent à la pousse suivante ; après la dernière mort, une graine garantie permet de continuer.

**Architecture:** `play/shop.js` (`FP.shop`, logique pure et animation de phase) ; `state.boosts` lus par les systèmes concernés ; nouveau mode `shop` dans `play/flow.js` ; `ui/order.js` (`FP.orderForm`) dessine le bon et donne ses zones de toucher ; `ui/menu.js` route les entrées.

**Tech Stack:** JavaScript vanilla (IIFE sur `window.FP`), Canvas 2D (`FP.px`, `FP.font`), Web Audio FM existant, banc `node dev/run-checks.js` (~100 s : lancer avec un long délai).

**Spec:** `docs/superpowers/specs/2026-10-23-boutique-design.md` ; maquette `docs/art/maquette-bon-de-commande.html`.

## Global Constraints

- Double-clic (file://) ; pas de `getImageData` dans `src/ui` ; `index.html` / `dev/check.html` : seulement des `<script>` ajoutés.
- Fichiers < 400 lignes, en-têtes Lit / Écrit / Expose à jour, pas de code mort ; seul `synth.js` crée des nœuds Web Audio.
- `state.rng` jamais consommé par la boutique : `FP.createRng((seed ^ shop.salt ^ Math.imul(visit, 2654435761)) >>> 0)`.
- Prix : seed 2500, membrane 700, magnet 500, premium 600, compost 600, spore 800, filter 700, beer 600, lobbying 900 ; promo ×.5 arrondie à 25 ; `lobbyingK: .6` ; compost ×.8 ; bière ×.3 ; aimant ×2 ; premium ×2.
- Score jamais < 0 ; le record ne baisse pas.
- Version `4.6.0`, CHANGELOG ; commits terminés par `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Précision de la spec : `FP.shop.open(state, { after })` avec `after ∈ 'death' | 'bloom' | 'last'` (`lastChance = after === 'last'`), pour que `afterShop` sache où reprendre.

## Review Focus

1. Commande avec Lobbying + Membrane : la regénération (`generate` + `prepare`) ne doit pas effacer le bouclier acheté — test Task 2.
2. Score exactement égal au prix : l'article est cochable et le score tombe à 0, pas en dessous — test Task 1.
3. Dernière chance refusée : certificat avec la cause de mort d'origine (`overReason` conservé) — test Task 3.
4. Toucher par réflexe juste à l'ouverture (phase `in`) : rien n'est coché ni commandé avant la fin de l'apparition — test Task 3.
5. Compteur du HUD : après une commande, il redescend au nouveau score (pas de reste de l'ancien) — test Task 5.
