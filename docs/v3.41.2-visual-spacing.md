# v3.41.2 — Visual Spacing Pass

But : supprimer l'effet de collage créé par les PNG authorés qui se superposent.

## Règle
- collision = gameplay ;
- empreinte visuelle = placement ;
- les deux restent indépendantes.

Pour le placement, chaque obstacle est représenté par une empreinte convexe orientée selon sa rotation et augmentée d'une marge. Un test SAT refuse toute intersection avec une empreinte déjà réservée.

## Marges par défaut
- PNG authoré : 7 unités monde ;
- T-Rex signature : 12 ;
- roche : 5 ;
- pipe / béton structurels : 4 ;
- autres solides : 6.

À terme, l'Asset Editor pourra exporter `spawn.visualPadding` pour autoriser une valeur spécifique par asset.

## Densité
La densité devient volontairement souple. Quand aucune position acceptable n'est trouvée, l'obstacle n'est pas posé. Aucun fallback ne contourne la règle de non-overlap.

## Hors périmètre
Les zones toxiques et le lixiviat peuvent toujours recouvrir visuellement les obstacles. Les power-ups restent absents de la génération du niveau, en attente du système flyover -> risque -> spawn dynamique.
